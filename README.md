# Dapur Kita

Katalog makanan komunitas berbasis React dan Vite, terhubung langsung ke Foods API (`https://foods.zetasolution.id`).

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Fitur katalog mencakup pencarian kata kunci, filter nama dan kontributor, pengurutan semua field yang didukung API, pilihan arah urut, ukuran halaman, pagination, dan penambahan makanan.

API dapat digunakan tanpa token. Aplikasi membutuhkan koneksi internet untuk mengakses API dan memuat font.
